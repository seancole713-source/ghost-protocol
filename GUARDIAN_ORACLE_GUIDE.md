## 🛠️ Technical Details

### **Files Created**

#### **`core/guardian_oracle.py` (900+ lines)**
- `GuardianOracle` class
- Morning prophecy formatter (mystical tone)
- 24/7 monitoring loop (every 5 min)
- Multi-tier alert system
- Database: `guardian_positions`, `guardian_alerts`, `guardian_heartbeats`

#### **`core/guardian_heartbeat_scheduler.py` (300+ lines)**
- Background thread scheduler
- 4 daily heartbeat check-ins
- Prevents duplicate sends
- Timezone-aware (configurable)

### **Files Modified**

#### **`core/daily_top_10_scanner.py`**
- Added `_register_with_guardian()` method
- Auto-registers all top 10 picks for monitoring
- Guardian watches them 24/7 after scan

#### **`wolf_app.py`**
- Replaced `top_10_scheduler` with `guardian_heartbeat_scheduler`
- Added `guardian.guardian_monitor_loop()` on startup
- Added 4 Guardian API endpoints

### **Database Schema**

```sql
-- Guardian positions (what's being watched)
CREATE TABLE guardian_positions (
    position_id INTEGER PRIMARY KEY,
    symbol TEXT NOT NULL,
    
    -- Original morning prophecy
    original_confidence REAL,
    original_target REAL,
    original_direction TEXT,
    entry_price REAL,
    
    -- Current status
    current_price REAL,
    current_confidence REAL,
    current_pnl_pct REAL,
    
    -- Position state
    status TEXT DEFAULT 'active',
    alert_count INTEGER,
    last_alert_time TEXT
);

-- Guardian alerts (what happened)
CREATE TABLE guardian_alerts (
    alert_id INTEGER PRIMARY KEY,
    position_id INTEGER,
    alert_type TEXT,
    severity TEXT,
    confidence_old REAL,
    confidence_new REAL,
    sent_at TEXT
);

-- Guardian heartbeats (scheduled check-ins)
CREATE TABLE guardian_heartbeats (
    heartbeat_id INTEGER PRIMARY KEY,
    heartbeat_type TEXT,
    positions_active INTEGER,
    sent_at TEXT
);
```
