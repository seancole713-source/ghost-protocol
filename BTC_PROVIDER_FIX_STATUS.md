### Provider Architecture**TurboProvider Design**(`core/providers/turbo_provider.py`)

-**Hard timeouts**: 2s per provider, 3s total budget

- **Parallel execution**: Sequential with short-circuit (first success wins)
- **Cache-first**: Check cache before hitting external APIs
- **Stale cache fallback**: Use expired cache if all providers fail
- **Health tracking**: Records success/failure rates per provider
- **Structured responses**: Always returns dict (never raises exceptions)


**Provider Chain Logic**:

1. Check fresh cache (TTL=5min) → instant return
2. Try Provider 1 with 2s timeout
3. If fail, try Provider 2 with remaining budget
4. Continue through chain until success or budget exhausted
5. Check stale cache (any age) → return with warning
6. Total failure → return error dict with detailed logs
