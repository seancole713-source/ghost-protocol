⚡ ALTERNATIVE: Manual Railway Deployment

If script doesn't work, do it manually:

1. railway login
2. railway init
   → Choose "Create new project"
   → Name: ghost-trading

3. Set variables (copy the production values directly from Railway → Variables):
  railway variables set GHOST_API_TOKEN "$(openssl rand -hex 32)"
  railway variables set POLYGON_API_KEY "$(railway variables get POLYGON_API_KEY --environment production)"
  railway variables set ALPHAVANTAGE_API_KEY "$(railway variables get ALPHAVANTAGE_API_KEY --environment production)"

4. Deploy:
   railway up

5. Get URL:
   railway domain

  → Check: railway whoami

Health check fails?
  → Wait 30 seconds for startup
  → Check logs: railway logs
